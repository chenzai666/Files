# 安装目录、窗口拖动与启动修复

修复旧版把 DEV 程序注册在临时目录，临时文件被清理后 Files 无法启动的问题。

- 开发注册使用 `%LOCALAPPDATA%\Programs\FilesDev` 下的独立持久目录。
- 完成解包、检查必需文件和安装运行库后，才切换旧 DEV 注册；保留应用数据和旧程序目录。
- 新包注册失败时，尝试恢复仍然完整的旧开发注册。
- 保留回收站完整 GUID、启动器同步和关联刷新修复。
- 兼容 EXE 实际调用的 Windows PowerShell 5.1；使用 ZIP API 解开 MSIX。
- 安装成功后自动清理不再注册的旧版本目录，不再随安装次数累积（每个旧目录约 430MB）。

## 窗口拖动

标题栏拖动时不再因每次窗口位置变化清除并重建命中区域；仅在窗口尺寸、显示状态、Presenter 或跨屏 DPI 变化时刷新。该策略已同时应用于主窗口和属性窗口。

## 启动修复

- 直接双击 `Files.exe` 时进程缺少包标识，会在初始化阶段闪退。现在启动入口检测到缺少包标识时自动转交系统包激活，以带标识的方式重启应用；无法转交时弹出明确的错误提示，不再静默闪退。
- 崩溃恢复标志残留但会话列表为空时，启动会回退到创建新标签，不再出现无标签的空白窗口。

旧版用户直接安装此版本。新版本不依赖原来的 Temp 目录。
