# 安装目录修复

修复旧版把 DEV 程序注册在临时目录，临时文件被清理后 Files 无法启动的问题。

- 开发注册使用 `%LOCALAPPDATA%\Programs\FilesDev` 下的独立持久目录。
- 完成解包、检查必需文件和安装运行库后，才切换旧 DEV 注册；保留应用数据和旧程序目录。
- 新包注册失败时，尝试恢复仍然完整的旧开发注册。
- 保留回收站完整 GUID、启动器同步和关联刷新修复。
- 兼容 EXE 实际调用的 Windows PowerShell 5.1；使用 ZIP API 解开 MSIX。

旧版用户直接安装此版本。新版本不依赖原来的 Temp 目录。旧程序目录不会自动删除，以便故障恢复。
